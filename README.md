# COVID-19 India Data Analysis

A Python-based data analysis project that explores COVID-19 trends in India through data cleaning, exploratory analysis, and visualizations. The project provides insights into case distribution, recovery rates, vaccination progress, and symptom patterns.

## Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- State-wise COVID-19 analysis
- Recovery and deceased rate analysis
- Vaccination trend analysis
- Daily and cumulative case visualization
- 7-day moving average analysis
- Symptom correlation analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses COVID-19 datasets containing information on confirmed cases, recoveries, deaths, vaccinations, and symptoms across India.

## How to Run

1. Clone or download the repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Ensure `python_data.xlsx` is in the same directory as the notebook.
4. Run all cells to reproduce the analysis and visualizations.

## Results

The analysis provides insights into COVID-19 trends across Indian states through various charts and visualizations, helping identify patterns in confirmed cases, recoveries, vaccinations, and symptom distributions.
