# COVID-19 India Data Analysis 

This project focuses on analyzing COVID-19 data in India using Python.

##  Tools Used
- Python 
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features
- Data cleaning and preprocessing
- State-wise analysis
- Visualization of COVID-19 trends
- Insights from real dataset

## Files Included
- covid19_india_analysis.ipynb → Main analysis notebook
- python_data.xlsx → Dataset used for analysis

## How to Run
1. Download the repository
2. Open Jupyter Notebook
3. Run `covid19_india_analysis.ipynb`

## Goal
To understand COVID-19 trends in India using data visualization and analysis.
